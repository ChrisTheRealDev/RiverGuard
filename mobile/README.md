# RiverGuard standalone Android

The Android app now bundles the dashboard and stores data on the phone. No laptop, Python, internet service or AI model is needed to explore the app. Real sensors use the phone receiver on the same private Wi-Fi.

See [the standalone guide](../docs/STANDALONE-ANDROID.md) for installation, sensor setup, storage, update and verification limits.

AI chat is not included. Rill provides clearly labelled rule-based reading notes. Sensor reception is limited to when the app is visible and enabled; it is not a background logger.
